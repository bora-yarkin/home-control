# Home Control user manual

Home Control is a dashboard panel for Home Assistant: a Home page, a page for each room, and the controls for what is in them. It shows and controls your
home; automations, helpers and integrations stay in Home Assistant.

The pictures in this manual show an invented demo home.

1. [Getting started](getting-started.md): install, the first run, finding your way.
2. [Pages, sections and the header](pages.md): rooms, the page editor, columns and widths, status tiles, showing things only when it matters.
3. [Devices](devices.md): adding them and what can be set for each.
4. [Lights and scenes](lights-and-scenes.md): the light popup, lights masters, the kinds of scene and the ways to arrange them.
5. [TVs, speakers and remotes](media-and-remotes.md): media players, the remote builder, the Remote master.
6. [Appliances and robot vacuums](appliances.md).
7. [Widgets](widgets.md).
8. [Security, cameras, door calls, climate and energy](home-and-safety.md).
9. [Settings](settings.md): appearance, wall screen, users and access, notifications, Siri and HomeKit, new devices.
10. [Backup and restore](backup.md).
11. [Troubleshooting](troubleshooting.md).

**Letting an AI set it up:** [the AI setup guide](../ai-setup.md) tells an assistant how to build a whole dashboard from your Home Assistant, as a file you restore.
