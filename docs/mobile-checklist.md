# Mobile acceptance checklist (iOS and Android, Home Assistant Companion)

Nothing here can be checked from a computer. Go through it on a phone and note what fails.

1. Open the dashboard; the header, room bar and a scroll of a long page behave; no horizontal scroll.
2. Open a popup (a light), scroll inside it, drag a slider with one finger, close it with the back gesture.
3. Remote (grid): open it, press a button, edit buttons as an administrator, add one with +, change columns.
4. Image remote: touch areas react to a tap and to a quick repeated tap; dragging a touch area in the editor moves it without scrolling the page; resizing by the corner works.
5. Everything-off button: shown on a room page, asks nothing, switches off what the room's list says.
6. Camera: live view starts; mute; full screen; leaving the page stops the stream.
7. Push to talk (only for a camera with it switched on): the first press asks for the microphone; holding talks, releasing stops; leaving the page or locking the phone while held stops it; a camera that does not take audio says so.
8. Intercom: answer and reject appear only while it rings; unlock asks to confirm and opens only the chosen door.
9. Appliance: Start is disabled with a reason when remote start is off; the time left counts down.
10. Alerts: a test notification arrives on the phone.
